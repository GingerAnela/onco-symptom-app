# Oncology Symptom Monitor (SMART on FHIR prototype)

A bilingual (English/Spanish) SMART on FHIR learning prototype for weekly symptom reporting during chemotherapy.
Uses fictional sandbox data only. Not for clinical use.

- `launch.html` starts SMART authorization.
- `index.html` reads the Patient and Conditions and creates a QuestionnaireResponse.

Test at https://launch.smarthealthit.org (Patient Standalone Launch, R4) with the launch URL
`https://YOURUSERNAME.github.io/onco-symptom-app/launch.html`.
